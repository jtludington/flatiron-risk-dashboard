# Flatiron Battery Project Risk Dashboard

[Open the interactive dashboard](https://jtludington.github.io/flatiron-risk-dashboard/)

An interactive prototype with Active Projects, personalized SHAP Risk Drivers, and Methodology tabs. It contains 12 fictional battery projects and precomputed outputs from a functioning CatBoost pipeline trained on synthetic historical snapshots.

Open `index.html` in any modern browser to use the dashboard offline. No Python installation or server is required.

This proof of concept demonstrates an end-to-end CatBoost risk-scoring pipeline using synthetic historical outcomes. Model performance reflects internal consistency with the simulated assumptions and is not evidence of real-world predictive validity. SHAP explanations are not causal estimates.
